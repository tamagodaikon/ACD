# チャレンジ問題

CTF（Capture The Flag）形式の練習問題です。各問題には「フラグ」があり、正解を見つけることで学習の確認ができます。

## 難易度別

| 難易度 | 対象者 | 必要な前提知識 |
|--------|--------|--------------|
| ⭐ Beginner | セキュリティ初心者 | Linux基礎、ネットワーク基礎 |
| ⭐⭐ Intermediate | 基礎を学んだ方 | Lab 01〜03の内容 |
| ⭐⭐⭐ Advanced | 実践経験者 | 全Labの内容 |

## フラグ形式

```
ACD{フラグの内容}
例: ACD{sql_injection_is_dangerous}
```
