## ツール一覧

### ネットワーク解析
```
Wireshark   - パケットキャプチャ・解析
nmap        - ポートスキャン・サービス検出
tcpdump     - コマンドラインパケットキャプチャ
Zeek        - ネットワーク監視フレームワーク
```

### Webセキュリティ
```
Burp Suite  - Webプロキシ・脆弱性スキャン（Community版無料）
OWASP ZAP   - オープンソースWebスキャナー
sqlmap      - SQLインジェクション自動化（自分の環境のみ）
nikto       - Webサーバースキャナー
```

### フォレンジクス
```
Volatility  - メモリフォレンジクス
Autopsy     - デジタルフォレンジクスプラットフォーム
binwalk     - ファームウェア解析
strings     - バイナリから文字列抽出
```

### ログ解析
```
ELK Stack   - Elasticsearch + Logstash + Kibana
Splunk      - SIEM（無料版あり）
GoAccess    - Webサーバーログ解析
fail2ban    - ブルートフォース自動ブロック
```
