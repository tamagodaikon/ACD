## 6. 根本原因

入力値のバリデーション不足により、ユーザー提供のファイルパスがそのままファイルシステムへのアクセスに使用されていた。

```python
# 脆弱なコード（修正前）
page = request.args.get('page')
with open(f'/var/www/html/{page}') as f:
    content = f.read()

# 安全なコード（修正後）
import os
BASE_DIR = '/var/www/html/pages'
page = request.args.get('page', 'index')
safe_path = os.path.realpath(os.path.join(BASE_DIR, page))
if not safe_path.startswith(BASE_DIR):
    abort(400)
```

## 8. 教訓

1. **入力値は常に検証・サニタイズする**: ユーザー入力をファイルパスに使う場合は必ずバリデーション
2. **最小権限の原則**: Webサーバーは `/etc/passwd` を読む必要がない
3. **WAFルールの定期見直し**: パストラバーサルパターンはWAFで検知できた
